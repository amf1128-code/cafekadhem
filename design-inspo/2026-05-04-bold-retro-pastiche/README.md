# Bold Retro Vintage Pastiche

**Date:** 2026-05-04

## The brief

Bold, retro, vintage-pastiche. Imagine if **Youssef Chahine** made a website — lots of saturated color, a bit of whimsy, 60s/70s confidence. Not clean, not minimalist café. Should feel like a poster pinned to the wall, not a SaaS landing page.

## Vibe in one paragraph

A site that reads like an old Egyptian magazine cover crossed with a 70s font specimen. Display type does heavy lifting — Arabic and Latin treated as equals, both decorative. Real photography, sometimes B&W, sometimes sepia/violet-tinted. Halftones, paper textures, taped-on edges. Saturated pinks, oranges, teals, mustards, navys on cream/off-white grounds. Layouts that sit somewhere between editorial print and zine collage.

## Hard yeses

- Bilingual treatment — Arabic display type as decorative equal, not afterthought
- Saturated color, not muted — pinks, oranges, teals, mustards, navys
- Display serifs / chunky 70s lettering for headers
- Real photography (B&W, sepia, or duotone), feels candid, not stock
- Stripes, halftones, paper grain, tape, stamps — print-collage texture
- Big confident hero type. Buttons that look like buttons (chunky, bordered, clearly clickable)
- Layouts can be asymmetric, busy, editorial. Negative space is fine but not the goal.

## Hard nos

- Sterile minimalism / "modern café" beige-and-sans-serif
- Thin hairline type for body or display
- Pastel washed-out palettes
- Generic stock photography
- Glassmorphism, neumorphism, ultra-rounded "friendly" SaaS look
